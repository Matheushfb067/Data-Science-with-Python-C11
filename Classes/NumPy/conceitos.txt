NumPy: aula 01

Biblioteca mãe do data science

O NumPy (Numerical Python) é uma biblioteca open source em
Python, largamente utilizada em quase todos os campos da
ciência
e engenharia


• Manipulação de arrays multidimentsionais como vetores e matrizes
• Grande variedade de operações matemáticas disponíveis • Preparada para lidar com grandes quantidades de dados
(Sua baseé criada na linguagem C)
• Biblioteca mãe de outras, como Pandas e MatplotLib

O NumPy tem uma estrutura chamada de NdArray ou NumPy Array - que indica o uso de estruturas especificas de numpy

Com o NumPy podemos aplicar tudo o que foi implementado em coleções, só que por meio de bibliotecas

broadcasting - quando um ESCALAR faz uma operação com um ARRAY

--------------------------------------------------------------------------------------------------------------------

Podemos realizar o Slicing de NumPy Arrays unidimensionais da mesma forma que fizemos 
com as Tuplas e Listas
Utilizaremos o Slicing de NumPy Arrays bidimensionais com frequência

Conceito mais importante do numpy: 
Condicionais no NumPy

-> Mata as estruturas de repetição da programação - dominando esse conceito raramente será necessrio for e while
-> Tudo que é possivel se fazer dentro de um if e else, será possivel se fazer dentro de um numpy array
